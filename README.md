# Proposed SirGRAMS Techstack

**Geo Risk Assessment Management System**

SirGRAMS is a geographic risk assessment and management system designed to collect, process, visualize, and assess natural disaster and geographic risk data.

## Tech Stack

### Frontend

* React Native
* Expo
* TypeScript
* NativeWind

### Backend

* Node.js
* Express
* TypeScript

### Database

* Supabase
* PostgreSQL
* PostGIS

### External Data
